PixelMind

Low-cost autonomous game testing with hierarchical AI agents
Bilkent University · CS491/492 Senior Design Project · 2026–2027

About the Project

Mobile game studios still rely heavily on manual QA because automated options fall short: random-tap tools do not understand the game and get stuck, while AI agents that send every frame to large multimodal models are too expensive to run at scale. PixelMind is an autonomous agent that tests 2D mobile games like a human tester, at a fraction of that cost. Lightweight local vision models turn each screen into a structured description of buttons, text and game state; a small decision layer handles routine actions, and a large language model is called only when the agent gets stuck. PixelMind explores games on its own, reports freezes, soft-locks and rendering glitches with steps to reproduce, and will be benchmarked on bug-detection rate and cost per test hour against existing approaches.
